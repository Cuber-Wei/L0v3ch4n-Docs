记录 L0v3ch4n 的 Mac 新机环境搭建清单。

基础软件

  1. Chrome: 执行效果最标准的浏览器。
  2. Clash Verge: 装机必备魔法软件。
  3. HomeBrew: 软件包管理神器，绝大部分软件均可通过 brew 安装。
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

系统体验优化类

  1. Supercharge: 超级好用的系统功能拓展工具，包含快捷键优化和实用小功能。
  2. MenuBar Spacing: 管理菜单栏图标之间的间距。
  3. Hidden Bar: 隐藏菜单栏项目的小工具。
  4. Pandan: 监控当前回话连续使用时间，提醒用户按时休息。
  5. Shareful: 赋予 macOS 分享菜单超能力。
  6. RunCat: 系统资源占用显示。
  7. Snipaste: 非常好用的截图工具。
  8. Alcove: Mac 上的灵动岛解决方案，优化刘海屏的使用体验。
  9. AppCleaner: 卸载软件时清除相关文件。

文字处理类

  1. Typora: Markdown 编辑器。
  2. WPS: 最终还得向 Word 屈服。

互联、共享类

  1. Tailscale: 多设备互联的实用工具。
  2. ToDesk: 桌面远控软件。

开发相关

  1. Visual Sutdio Code: 微软做的最好的软件（真）。
  2. WakaTime: 记录每天的编码时间。
  3. Postman: 接口调试工具。
  4. Docker: 容器化伟力。
  5. MySQL
  6. Redis
  7. Warp: 好看强大的终端模拟器。

环境配置

  1. uv: 现代的 Python 包管理器。
  2. nvm: Node.js 环境管理器。

其他

  1. 7zip: 好用的解压缩软件。
    brew install p7zip
  2. btop: 电脑资源占用监控软件。
  3. fastfetch: 解决了 MacOS 上没有刷新键的问题。
